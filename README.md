**Technologies:** Python | Tacotron | Tacotron 2 | PyTorch | Librosa | HiFi-GAN

- Developed an emotion-controlled Text-to-Speech system using a Tacotron-based deep learning architecture.
- Integrated emotion representations into text embeddings to generate expressive speech.
- Worked with the Emotional Speech Database (ESD) for emotion-aware speech synthesis.
- Implemented Mel Spectrogram generation and explored attention-based sequence-to-sequence modelling.
- Explored Griffin-Lim and HiFi-GAN vocoder approaches for speech waveform generation.

### 2. 📸 Face Recognition Attendance Management System

**Technologies:** Python | Flask | OpenCV | SQLite

- Developed a web-based attendance management application using Python and Flask.
- Implemented face detection using Haar Cascade Classifier.
- Used LBPH Face Recognizer for facial recognition.
- Automated attendance recording and maintained attendance information using SQLite.
- Developed a web interface for managing attendance records.

### 3. ⚙️ Windows Registry Editor MRU Cleaner

**Technologies:** C | Windows API (WinAPI)

- Developed a Windows utility to identify and manage Most Recently Used (MRU) registry entries.
- Implemented Windows Registry operations using C and WinAPI.
- Explored system-level programming and Windows registry management.
- Focused on safe handling of registry entries and system organization.

### 4. 💻 Laptop Configuration & Pricing Management System

**Technologies:** React.js | JavaScript | Vite | Material UI | React Router

- Developing a web-based system for managing laptop components and configurations.
- Implementing component management with create, read, update, and delete operations.
- Building a laptop configuration interface with automatic price calculation.
- Working on component-wise cost breakdowns and historical pricing preservation.
- Developing search, filtering, and configuration management functionality.
- Building a responsive interface for sales executives.
